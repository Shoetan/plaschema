# Project instructions

Before making changes, read:

1. `docs/HANDOFF.md`
2. `docs/feature-folder-structure.md`
3. `docs/routing-entry-pattern.md`

Keep `docs/HANDOFF.md` current after any major feature, architecture, command, or integration change.

Important rules:

- `frontend/` is the admin web app.
- `pwa/` is the field-worker mobile PWA.
- Do not change `backend/` unless the user clearly asks for backend work.
- Never put credentials, tokens, or `.env` values in documentation.
- Preserve unrelated user changes in the working tree.
